## 3. Critical Product Gaps

### P0: Photo-first demo is not real yet

Current behavior:

- Signed-out photos are local previews only.
- The AI request contains text, place, and mood.
- The AI does not inspect the selected photos.
- The UI supports up to 6 photos, not 20.
- No EXIF extraction exists.
- No event clustering exists.

Required Paid Public Alpha behavior:

- Accept text, photos, or both.
- Accept 1-20 valid images.
- Extract EXIF locally when possible.
- Compress images in the browser before any temporary AI processing.
- Send only a bounded representative set to vision processing.
- Do not persist anonymous originals.
- Generate a draft, then require fact confirmation before permanent save.

### P0: Facts and narrative are not separated

Current `memories` data mixes generated and factual content and has no event date, date precision, explicit coordinates, people, factual summary, or narrative provenance columns.

Required:

- Store event date separately from `created_at`.
- Store latitude/longitude separately from place label.
- Store factual summary separately from AI story.
- Record model, generation source, and confirmation state.

### P0: Private-by-default is not enforced at every layer

Current migration `0005_memory_visibility.sql` adds:

`is_public INTEGER NOT NULL DEFAULT 1`

Current POST behavior also treats missing `isPublic` as public.

Required:

- New database default must be private.
- API must make content public only when `isPublic === true`.
- Existing public records must not be silently changed.
- Public feed can remain for legacy content but is removed from the primary conversion path.

### P0: Media access is not private enough

Current `GET /api/media?key=...` returns any R2 object when the key is known. It does not verify ownership or a share token.

Required:

- Owner-authenticated media access for private memories.
- Explicit share-token access for shared traces.
- Revocable share records.
- No media key exposure as the permission mechanism.

### P0: Billing and usage controls do not exist

Required:

- Guest: one complete temporary generation.
- Registered Free: up to 3 saved traces.
- Founding Plus: `$9.99/month` or `$79/year`.
- Founding Plus: up to 500 traces and 50 AI generations per month.
- Stripe Checkout, webhook verification, customer portal, and server-side entitlements.
- Cost and rate controls independent of frontend buttons.

### P0: English-first positioning is not reflected in production

Current homepage defaults to Chinese metadata, Chinese UI, and the old `AI Life Memory OS` / community-publishing framing.

Required:

- English default content and metadata.
- `AI Life Atlas` category language.
- Primary CTA: `Create your Life Atlas`.
- Photo-led capture.
- Community removed from the primary homepage path.
- Chinese can remain available as a secondary interface during transition, but no new Chinese SEO expansion.

## 5. Map Decision

The current Leaflet implementation works but does not satisfy the desired WebGL direction and directly depends on public tile/geocoding services.

Paid Public Alpha target:

- MapLibre GL JS for the new synchronized Atlas experience.
- OpenFreeMap as the initial tile source.
- Tile provider isolated behind configuration so it can be replaced.
- EXIF coordinates preferred over external geocoding.
- Avoid building 3D in the launch window.

Fallback:

If MapLibre migration threatens launch stability, retain Leaflet for the 2026-08-15 release and move MapLibre to the first post-launch sprint. Billing, privacy, factual data, and activation take precedence over renderer replacement.

## 7. Audit Conclusion

The product is not starting from zero. The fastest credible path is to convert the existing stable prototype into a narrow paid product.

The critical path is:

`photo/text input -> factual draft -> AI narrative -> confirmation -> sign-up/save -> private Atlas -> limit -> checkout -> entitlement -> revisit`

Historical SEO remains strategically important, but only one flagship historical Atlas is a launch target. The full set of three remains the first post-launch content milestone.
